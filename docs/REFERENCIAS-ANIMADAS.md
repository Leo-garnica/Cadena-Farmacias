## Tu decisión visual (rellenar con el equipo antes de implementar)

Elige **máximo tres patrones**, preferiblemente uno por necesidad, no todos los de la galería.

- Pantalla a diseñar (ruta real): `POR CONFIRMAR`.
- Referencia **A** para composición/estética: `N.º __` porque `__`.
- Referencia **B** para interacción funcional: `N.º __` porque `__`.
- Referencia **C** para identidad/microinteracción: `N.º __` porque `__`.
- Efecto que **NO** quieres: `__`.
- Nivel de movimiento aprobado: `mínimo / equilibrado / expresivo (solo landing)`.
- Aprobado por / fecha: `__`.

## Método de evaluación en 90 segundos por referencia

1. Abre el enlace en escritorio y, si existe una demo, interactúa con ella (hover, clic, scroll).
2. ¿Te ayuda a entender un cambio de estado o solo decora?
3. ¿Se entiende la UI sin movimiento y sin usar el mouse?
4. ¿Podría distraer durante un flujo operativo repetitivo?
5. Anota qué copiarías **como principio**, no como código, imagen, marca o assets.

**Origen:** enlaces verificados mediante páginas públicas y resultados de búsqueda en octubre de 2026. Que una referencia esté publicada no implica que la animación se reproduzca en todos los navegadores o que pueda accederse sin iniciar sesión.
